## 第3组跳跃参数

| 项目 | 内容 |
| --- | --- |
| 参数基准 | 2026-10-19 当前 `jump_mit` / `jump_test` 版本；下列为默认参数及总运动质量 6.2 kg 时的基准值。`jump_test` 的 V_PUSH、周期、次数、总质量为必填参数；<span style="color: #e03131">本次试跑分别为 450 deg/s、3 s、10 次、6.2 kg，</span>不等同于 `jump_mit` 的 V_PUSH 默认值。 |
| <span style="color: #2f9e44">蹬伸角度 push</span> | ID1 = -13.20°，ID2 = 1.99°，ID3 = -2.905567° |
| <span style="color: #2f9e44">落地准备角度 land</span> | ID1 = 11.96°，ID2 = 10.60°，ID3 = -2.905567° |
| <span style="color: #2f9e44">缓冲最深点 land_deep</span> | ID1 = 71.00°，ID2 = 30.61°，ID3 = -2.905567° |
| 控制与单位 | <span style="color: #2f9e44">1 kHz 力位混合指令；位置、速度在程序内用度及 deg/s，下发转换为 rad、rad/s；前馈及摩擦补偿单位为 N·m，反馈第三量沿用电流 A。</span> |
| 启动到 stand、下蹲到 crouch | 五次插值，两端速度、加速度为 0；时长按 ID1 位移绝对值 / 115 deg/s 计算，ID1 无位移时用 ID2 位移计时；两轴同步。stand → crouch 约 0.3475 s，115 deg/s 是时长基准而非五次曲线峰值限速。 |
| 蹬伸前保持 | `jump_mit` 在 crouch 保持 0.3 s；`jump_test` 每周期下蹲后直接蹬伸，无此额外保持。 |
| 蹬伸速度与时长 | `jump_mit` 的 V_PUSH 默认 340 deg/s；前 40 ms 从 0 线性加到 V_PUSH，随后匀速到 push，ID2 按位移比例同步。正常行程时长为 ID1 位移绝对值 / V_PUSH + 0.020 s；短行程在加速段内截断。 |
| 蹬伸结束等待 push_wait | push 插值结束后保持 push、速度指令为 0；ID1 实际位置与 push 的绝对偏差 < 3°，或等待达到 0.2 s，进入空中段。 |
| 空中到 land | 无 tuck 阶段；从两轴当前实际位置、实际速度出发，五次插值 0.09 s 到 land，终点速度为 0，两端加速度取 0。 |
| 布防 land_arm | 保持 land；ID1 位置误差绝对值 < ARM_DEG（默认 4°），且实际速度绝对值 < 100 deg/s，连续满足 20 ms 后进入 land_wait；任一条件不满足则重新计时，不设超时。 |
| 触地检测 land_wait | 保持 land，每周期判断：ID1 实际位置 − 指令位置 > TD_DEG（默认 3°），或 ID1 实际速度 > TD_VEL（默认 150 deg/s，弯曲为正），任一满足即触地。完整跳跃及 `jump_test` 等待超过 0.3 s 也按触地处理；`jump_mit drop` 无此超时。 |
| 缓冲 absorb 参数 | V_ABS0 默认 450 deg/s，替代原固定 T_ABS；从两轴触地时的实际位置出发，不使用实测初速度。T = 3 × abs(71.00° − ID1 实际位置) / V_ABS0，两轴共用 T。 |
| 缓冲 absorb 轨迹 | 对各轴分别令 Δ = land_deep 目标位置 − 触地实际位置；s(t) = Δ × \[1 − (1 − t/T)³\]，v(t) = (3Δ/T) × (1 − t/T)²。终点精确为 land_deep，速度、加速度为 0。 |
| 最深点保持 land_deep_hold | 在 land_deep 保持 0.15 s，沿用缓冲增益。 |
| 回站 stand_return | 从 land_deep 用五次插值在 0.5 s 内回 stand，两端速度、加速度为 0；增益同时在这 0.5 s 内渐变回 80 / 2。 |
| 连续跳跃周期 | `jump_test` 周期包含下蹲 → 蹬伸 → 空中到 land → 布防 → 等待触地 → absorb → 最深点保持 → 回 stand；回站后等待本周期结束。本次周期 3 s；动作超期不截断、不追赶旧周期，全部次数完成后保持 stand。 |
| drop 模式 | 慢速线性插值到 land → land_arm → land_wait → absorb → land_deep 保持 0.15 s → 0.5 s 五次插值回 stand → 持续保持至手动退出。 |
| 常规与蹬伸增益 | ID1、ID2 共用一组增益：常规 Kp = 80、Kd = 2；蹬伸及 push_wait 为 Kp = 250、Kd = 3。 |
| 空中与落地增益 | Kp_LAND 默认 25、Kd_LAND 默认 3；从空中插值开始渐变到此值，land_arm、land_wait 沿用。 |
| 缓冲增益 | Kp_ABS 默认 40、Kd_ABS 默认 3.5；触地后 30 ms 内从当前落地增益渐变过去，absorb 及最深点保持沿用。 |
| 增益渐变规则 | ID1、ID2 的增益切换通常为 30 ms 线性渐变（启动从 0 / 0 渐变）；回 stand 特别采用 0.5 s 渐变。ID3 全程固定 Kp = 80、Kd = 2。 |
| 重力前馈 | ID1：r = clamp((ID1 指令位置 − 17.61) / (57.57 − 17.61), 0, 1)，tor_ff = TOR_FF_STAND + (TOR_FF_CROUCH − TOR_FF_STAND) × r；默认 TOR_FF_STAND = -3 N·m、TOR_FF_CROUCH = -4.5 N·m。空中、land_arm、land_wait 关闭重力前馈；触地进入 absorb 后 50 ms 内将线性系数从 0 增至 1，恢复当前姿态对应的前馈。ID2、ID3 不加重力前馈。 |
| 摩擦补偿 | TOR_FRIC 默认 1.5 N·m；所有运动阶段（包括空中），ID1、ID2 在指令速度绝对值 ≥ 5 deg/s 时额外叠加 TOR_FRIC × sign(速度指令)，低于 5 deg/s 时不加；ID3 不加。 |
| 配重补偿 | 仅 `jump_test`：k = 总质量 / 6.2，TOR_FF_STAND、TOR_FF_CROUCH、Kp_LAND、Kd_LAND 乘以 k，Kd_LAND 最大为 5；缓冲增益及摩擦补偿不随质量缩放。本次总运动质量 6.2 kg，k = 1。 |
