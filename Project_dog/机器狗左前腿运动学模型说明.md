# 机器狗左前腿运动学模型说明

Oct 12, 2026 · @Johnny

## 1. 概述

输入足端位置 (x, y, z)，输出 HAA、HFE、膝三个电机的角度；也支持反向和雅可比。实现文件为 `dog_leg_kinematics.py`，几何参数全部取自 `Ljsz-1.2-06-00-00.STEP`（单文件导出版）。

| 项目 | 内容 |
| --- | --- |
| 输入 | 足端球心位置，mm，髋坐标系；单点 (3,) 或轨迹 (N,3) |
| 输出 | `[q1, q2, q3]`：HAA、HFE、膝电机的驱动器指令角，rad |
| 反向 | 电机角 → 足端位置 |
| 速度/力 | 足端速度 = J·关节角速度；电机力矩 = Jmᵀ·足端力 |
| 可下发判据 | `info['ok']`：有解且膝角离平行四边形死点 ≥ 10° |
| 依赖 | uv 管理的 Python 环境 + NumPy |

三个关节都是闭式解，没有迭代；本模型只含运动学，不含质量与动力学。

## 2. 机构结构

腿是 HAA、HFE、膝三关节串联；膝电机定子装在大腿上，经 18/26 齿轮和平行四边形驱动小腿，整条腿没有需要迭代的闭链。

&#91;embedded content: 运动链 · 3 个串联关节 + 膝关节传动\]

连接关系按螺钉分布判定：EC-A6408 的输出法兰用半径约 17.5 mm 的 6 孔圆，外壳用半径 40 mm 的 8 孔圆。

| 连接 | 螺钉位置 | 结论 |
| --- | --- | --- |
| HAA 输出 → 胯关节支架 | CAD x = −219.9，r ≈ 17.5 | 支架随 HAA 转动 |
| HFE 输出 → 连接座 | CAD z = 30.4，r ≈ 17.5 | 连接座随 HFE 转动 |
| 连接座 → 膝电机外壳 | CAD z = 53.4，r = 40 | 膝电机定子随 HFE 转动 |
| 膝电机外壳 → 大腿板 | CAD z = 94.6，r = 40 | 大腿与膝电机定子是同一刚体 |
| 膝电机输出 → 输出轴 → 18 齿 | CAD z = 103.5 / 113 | 18 齿随膝电机转子转动 |

HFE 限位块装在膝电机组上、限位底座装在胯关节组上，也印证了膝电机组属于 HFE 的转动侧。

## 3. 坐标系与零位

髋坐标系按 ROS REP-103 取 x 前、y 左、z 上，原点为髋中心 H（HAA 轴与 HFE 轴的交点），单位 mm、rad。

| 髋坐标系 | 对应 CAD | 说明 |
| --- | --- | --- |
| 原点 H | (−270.9, 238.0, 0) | 两电机轴线交点，CAD 中精确相交 |
| x（前） | −X | 推定，见下 |
| y（左） | +Z | 腿位于 HAA 轴的 +Z 侧，文件名为左前腿 |
| z（上） | +Y | 大腿在零位时指向 −Y |

“左前腿”位于 CAD +Z 一侧，因此 +Z 为左；结合 Y 向上，由右手系得前方为 CAD −X。若实际朝向不同，只需修改代码中的 `CAD2HIP`。

| 关节角 | 转轴 | 正方向 |
| --- | --- | --- |
| θ1（HAA） | +x | 腿向左外摆 |
| θ2（HFE） | +y | 大腿向后摆 |
| θ3（膝，小腿相对大腿） | +y | 小腿向下伸直；θ3 = 90° 为完全伸直 |

零位 θ = (0, 0, 0) 即 CAD 装配姿态，也是装上 5 个零点工装时的姿态：大腿竖直向下，小腿水平朝前，膝角 90°，足端球心在 (210, 120.5, −213)。

## 4. 几何参数

模型只需要 3 个长度和 1 个传动比；其余参数用于校核和限位（对应代码中的 `LegGeometry`）。

| 参数 | 代码字段 | 数值 | 来源（CAD 坐标，mm） |
| --- | --- | --- | --- |
| 侧向偏距 | `d` | 120.5 | 足端球心与连杆中面的 Z 坐标 |
| 大腿长 | `L1` | 213.0 | HFE 轴 (−270.9, 238) → 膝铰链销 (−270.9, 25) |
| 小腿长 | `L2` | 210.0 | 膝铰链销 → 足端球心 (−480.9, 25, 120.5) |
| 膝传动比 | `knee_ratio` | −18/26 = −0.6923 | 齿轮型号 VNG01-1.5-18 / -26 |
| 足端球半径 | `foot_r` | 25.71 | 足端的球面 |
| 齿轮中心距 | — | 33.0 | 实测，与 (18+26)×1.5/2 一致 |
| 曲柄 / 小腿摇杆 | — | 22.0 / 22.0 | 26 齿轴心 → 曲柄销；膝销 → 小腿销 |
| 连杆 / 机架 | — | 180.20 / 180.20 | 曲柄销 → 小腿销；26 齿轴心 → 膝销 |

两组对边分别相等且方向一致（曲柄向量 (21.78, 3.06)，摇杆向量 (21.79, 3.06)），确认膝传动是严格的平行四边形。STEP 不含材料，质量与惯量未提取。

## 5. 膝关节传动

膝关节角与膝电机角是固定比例：膝电机转 1.444°，膝关节转 1°，方向相反。

```latex
\theta_3 = -\frac{18}{26}\,\Delta q_3 = -0.6923\,\Delta q_3
```

推导分三段：

1. 膝电机定子在大腿上，所以 Δq3 本身就是 18 齿齿轮相对大腿的转角，与 HFE 角 θ2 无关，不需要做差。
2. 外啮合使 26 齿齿轮反向转动 18/26 倍；曲柄固定在 26 齿齿轮上。
3. 平行四边形使小腿摇杆始终与曲柄平行，因此小腿相对大腿的转角等于曲柄相对大腿的转角。

平行四边形在曲柄与机架共线时进入死点，此后可能翻转成反平行四边形。零位时曲柄与机架的夹角为 99.06°（接近传力最好的 90°），由此得到死点：

| 死点 | θ3 | 含义 |
| --- | --- | --- |
| 折叠方向 | −99.06° | 小腿向大腿折叠，实际会先发生干涉 |
| 伸直方向 | +80.94° | 腿离完全伸直（90°）还差约 9°，腿永远无法完全伸直 |

代码默认在两个死点前各留 10°（`knee_margin_deg`），即可用膝角为 −89.06° \~ +70.94°。

## 6. 正运动学

足端球心位置由三次转动直接写出；对应 `LegModel.fk()`。

```latex
p = R_x(\theta_1)\left[\begin{pmatrix}0\\ d\\ 0\end{pmatrix} + R_y(\theta_2)\left(\begin{pmatrix}0\\ 0\\ -L_1\end{pmatrix} + R_y(\theta_3)\begin{pmatrix}L_2\\ 0\\ 0\end{pmatrix}\right)\right]
```

侧偏 d 沿 HFE 轴方向，不受 θ2、θ3 影响，只随 θ1 转动。展开腿平面内的分量：

```latex
x = -L_1\sin\theta_2 + L_2\cos(\theta_2+\theta_3),\qquad z' = -L_1\cos\theta_2 - L_2\sin(\theta_2+\theta_3)
```

然后 p = (x, d cos θ1 − z′ sin θ1, d sin θ1 + z′ cos θ1)。零位代入得 (210, 120.5, −213)，与 CAD 足端球心一致。

雅可比 J = ∂p/∂θ 用于速度与静力学：足端速度 = J·θ̇，关节力矩 = Jᵀ·F。代码中 `jacobian()` 用数值差分计算，`motor_jacobian()` 已乘入膝传动比。

## 7. 逆运动学

给定足端球心 p = (px, py, pz)，三个关节角依次闭式求出；对应 `LegModel.ik()`。

1. **HAA。** 绕 x 轴转动不改变 y–z 平面内到原点的距离，腿平面内的竖直分量为 z′ = −√(py² + pz² − d²)，取负号表示腿在髋下方：

```latex
\theta_1 = \operatorname{atan2}(p_z, p_y) - \operatorname{atan2}(z', d)
```

2. **膝。** 腿平面内髋到足端的距离只由膝角决定：

```latex
\sin\theta_3 = \frac{p_x^2 + z'^2 - L_1^2 - L_2^2}{2L_1L_2}
```

3. **HFE。** 令 v = (L2 cos θ3, −L1 − L2 sin θ3)，即 θ2 = 0 时的足端向量，θ2 是把 v 转到 (px, z′) 所需的角度：

```latex
\theta_2 = \operatorname{atan2}(v_z, v_x) - \operatorname{atan2}(z', p_x)
```

**解的唯一性。** 平面两连杆通常有两支解（θ3 与 180° − θ3，即向前屈膝与向后屈膝）。第二支落在 θ3 > 90° 或 < −90°，超出平行四边形死点范围（−99° \~ +81°），实际到不了，所以取 θ3 = arcsin(·) 即为唯一可用解，不存在换支问题。

**无解与拒绝下发的情形**：py² + pz² < d²（足端离 HAA 轴比侧偏还近）；|sin θ3| > 1（超出腿长）；θ3 离死点不足 `knee_margin_deg`。前两种 `info['joint']` 为 nan，三种情形 `info['ok']` 都为 False，`info['reason']` 给出原因。

## 8. 电机角映射与标定

关节角到驱动器指令角是逐轴的线性关系，每个电机只需标定方向 sign 和零点 offset（对应 `Calibration`）：

```latex
q_1 = s_1\theta_1 + o_1,\qquad q_2 = s_2\theta_2 + o_2,\qquad q_3 = s_3\,\frac{\theta_3}{-18/26} + o_3
```

零点工装让标定很直接：装上工装时三个关节角都是 0。

| 工装 | 位置 | 固定的关节 |
| --- | --- | --- |
| LDGZ-01 / LDGZ-01-JX 髋部零点工装 | HAA 电机两侧 | θ1 = 0 |
| LDGZ-02-01 / 02-02 大腿零点工装 | HFE 限位块与限位底座之间 | θ2 = 0 |
| LDGZ-03 大小腿零点工装 | 大腿与小腿之间，膝销附近 | θ3 = 0（膝角 90°） |

1. 装上全部零点工装，驱动器不使能，记录三个电机读数作为 offset。
2. 拆掉工装，低刚度下逐个让电机小幅正转，对照第 3 节的正方向：HAA 正转时腿应向左外摆，HFE 正转时大腿应向后摆。膝电机正转时，模型中小腿应向上折叠（因为传动比为负）。方向一致 sign 填 +1，否则填 −1。
3. 下发几个小幅足端位置，用 `motor_to_foot` 读回编码器验证。

```python
import numpy as np
from dog_leg_kinematics import LegModel, Calibration
cal = Calibration(sign=np.array([+1, -1, +1]),            # 示例值，按实测填写
                  offset=np.array([0.214, -1.302, 0.877]))  # 示例值，rad
leg = LegModel(calib=cal)
```

q3 不需要减去 q2：膝电机定子装在大腿上，编码器读数本身就是相对大腿的角度。

## 9. 代码接口

常用的是 `foot_to_motor` 与 `motor_to_foot` 两个方法；单点和轨迹用同一接口，长度单位 mm，角度单位 rad。

```python
from dog_leg_kinematics import LegModel
leg = LegModel()                                   # 默认几何、未标定、死点余量 10°

q, info = leg.foot_to_motor([0, 120.5, -300])     # 足端在髋正下方 300 mm
# info['joint'] = [0, 0.775, 0.006] rad，info['ok'] = True

Q, infos = leg.foot_to_motor(foot_traj)            # foot_traj: (N,3) -> Q: (N,3)
bad = [k for k, i in enumerate(infos) if not i['ok']]

p  = leg.motor_to_foot(q_measured)                 # 编码器 -> 足端位置
Jm = leg.motor_jacobian(q_measured)                # 足端速度 = Jm @ 电机角速度
tau = Jm.T @ F_foot                                # 足端力 F (N) -> 电机输出端力矩 (N·mm)
```

| 接口 | 输入 | 输出 |
| --- | --- | --- |
| `LegModel(geometry, calib, knee_margin_deg)` | 均可省略 | 模型对象 |
| `foot_to_motor(p)` | (3,) 或 (N,3) 足端球心，髋坐标系 | 指令角 q，及 info（joint / ok / reason） |
| `motor_to_foot(q)` | (3,) 或 (N,3) 驱动器读数 | 足端球心位置 |
| `fk(th)` / `ik(p)` | 关节角 / 足端位置 | 足端位置 / (关节角, ok, reason) |
| `jacobian(th)` / `motor_jacobian(q)` | 关节角 / 电机角 | 3×3 雅可比 |

其他三条腿：右腿把 `d` 取负，前后腿的 x 方向与零位朝向按各自装配确认后复用同一模型。移植到 C++ 时，正逆解都是闭式运算，可逐行翻译。

## 10. 验证与未建模项

模型数值自洽，并与 CAD 一致：零位足端与 CAD 足端球心完全重合；5 组关节角做正解再逆解，误差在 1e-14° 量级。在项目根目录执行 `uv sync` 后，运行 `uv run python dog_leg_kinematics.py` 可复现。

| 未建模项 | 影响 | 建议 |
| --- | --- | --- |
| HAA、HFE 限位块的角度范围 | 关节可能先撞限位 | 实测，或在 CAD 中转到限位块接触后读角度 |
| 零件干涉（小腿与大腿、腿与机身） | 可用工作空间比运动学结果小 | 在 CAD 中扫描关键姿态 |
| 足端触地点 | 末端点取的是足端球心 | 平地上触地点 = 球心沿地面法向下移 25.71 mm |
| 齿轮侧隙、连杆销间隙 | 膝关节有小幅回差 | 需要时实测并在控制中补偿 |
| 质量与动力学 | 无法做重力补偿、力矩前馈 | STEP 无材料信息，需在 SolidWorks 中导出质量属性 |
